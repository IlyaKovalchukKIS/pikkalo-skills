# Аккаунт, вход, личный кабинет, подписка

## Когда просить вход
Не на старте. Сначала ценность: доступ к галерее → «нашли 2,1 ГБ» → первый разбор.
Вход — когда нужен: подключить Яндекс Диск, сохранить прогресс между устройствами,
отправить отзыв, оформить подписку (позже).

## Бэкенд — Yandex Cloud
Данные пользователей хранятся в РФ (152-ФЗ). Всё в одном каталоге облака `pickly`:
| Компонент | Сервис |
|---|---|
| HTTP API | API Gateway → Cloud Functions (Node.js 22, TypeScript) |
| База | YDB Serverless (бесплатный объём покрывает старт) |
| Секреты | Lockbox (ключ подписи JWT, токен GitHub, токен бота) |
| Логи | Cloud Logging, без персональных данных в тексте |
Код — в репозитории приложения, папка `backend/`; деплой — `yc` CLI или Terraform из CI.

## Вход
Supabase и сторонний Auth не используем — сессии выдаёт своя функция `auth`.
| Способ | Клиент | Сервер |
|---|---|---|
| Яндекс ID | нативный Yandex LoginSDK (или `expo-auth-session`) → OAuth-токен. Scopes: `login:info login:email cloud_api:disk.read cloud_api:disk.write` | `POST /auth/yandex` проверяет токен через `login.yandex.ru/info`, находит/создаёт пользователя |
| Google | `@react-native-google-signin/google-signin` → ID token | `POST /auth/google` проверяет подпись по JWKS Google, `aud` = наш client ID |
| Apple | при выходе iOS | `POST /auth/apple` |

Сессия: access JWT (ES256, 15 мин) + refresh-токен (случайный, 60 дней, в базе только
хэш, ротация при каждом обновлении — `POST /auth/refresh`). На устройстве — в
`expo-secure-store`. Токен Яндекса для Диска — тоже только на устройстве.

Связывание способов входа: автоматически по подтверждённой почте; вручную — «Привязать
ещё способ входа» в кабинете.

Удаление аккаунта (`DELETE /me`) — стирает все данные кабинета; фото не трогает.

## Данные (YDB)
| Таблица | Поля |
|---|---|
| `users` | id, yandex_id, google_sub, email, display_name, locale, created_at |
| `sessions` | id, user_id, refresh_hash, device, expires_at |
| `stats` | user_id, xp, level, photos_reviewed, photos_trashed, bytes_freed, series_reviewed, best_picked, combo_max, week_film (битовая маска дней), freezes, updated_at |
| `achievements` | user_id, code, unlocked_at |
| `storages` | user_id, provider, account_label, quota_total, quota_used, connected_at |
| `feedback` | id, user_id, kind, text, screen, app_version, status, issue_number, created_at, updated_at |
Только агрегаты: Витрина, квесты, люди и места считаются и хранятся на устройстве.
Синхронизация статистики — пакетом после сессии разбора, офлайн — очередь.

## Личный кабинет — разделы
1. **Прогресс и награды** — уровень куратора и шкала до следующего, освобождено ГБ,
   Плёнка недели, значки (закрытые — силуэт с подсказкой), ссылка на Витрину и итоги месяца.
2. **Хранилища** — Телефон, Яндекс Диск: занято/свободно, сколько можно освободить,
   «Отключить» (удаляет токен с устройства и строку `storages`; фото не трогает).
3. **Подписка** — пока «Ранний доступ: всё бесплатно». После подключения магазина —
   тариф, продление, «Восстановить покупки».
4. **Мои отзывы** — статусы (на рассмотрении → в работе → сделано / отклонено), «Написать
   отзыв» (ошибка / идея / другое; скриншот — только по явному выбору, без EXIF/GPS).
5. **Настройки** — режим разбора, напоминания, язык, «Люди» (вкл/выкл, удалить данные
   о лицах), выход, удаление аккаунта.

## Подписка (позже)
- Единый интерфейс `Entitlements` в приложении: `isPro`, `products`, `purchase`, `restore`.
- Реализации: RuStore Pay SDK (РФ) и Google Play Billing (за рубежом); сервер проверяет
  чек и хранит entitlement.
- Бесплатно: галерея телефона, базовые категории, дневной лимит действий (Remote Config).
- Pro: Яндекс Диск и будущие облака, без лимита, Люди и Места, итоги месяца.
- Пейволл — по правилам `copy-marketing.md`.
