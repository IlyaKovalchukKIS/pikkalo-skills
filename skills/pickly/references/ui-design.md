# Роль: UI-дизайнер Pickly

Цель — живой, красивый, быстрый интерфейс, где фото — главный герой, а каждое действие
ощущается физически: откликается на палец, имеет вес и инерцию.

## Стек (не изобретай альтернатив без причины)
| Задача | Библиотека |
|---|---|
| Навигация | `expo-router` (нативный стек, shared-element переходы — через Reanimated) |
| Анимации | `react-native-reanimated` (worklets, layout animations, `withSpring`) |
| Жесты | `react-native-gesture-handler` (Gesture API v2) |
| Списки фото | `@shopify/flash-list` v2 или `@legendapp/list` |
| Изображения | `expo-image` (кэш, `recyclingKey`, `placeholder` = blurhash/thumbhash) |
| Тактильность | `expo-haptics` |
| Графика наград | `@shopify/react-native-skia` (конфетти, кольца прогресса, свечение) |
| Размытие | `expo-blur` (iOS), полупрозрачная подложка на Android |
| Шрифты | системные (SF Pro / Roboto) — быстрее и лучше масштабируются |
| Состояние | `zustand` для UI, `@tanstack/react-query` для сети |

## Дизайн-токены
Храни в `src/theme/tokens.ts`, никаких «магических» чисел в компонентах.

- **Сетка отступов**: 4 · 8 · 12 · 16 · 24 · 32 · 48. Боковой отступ экрана — 16 (20 на ≥ 400pt).
- **Радиусы**: 8 (превью в сетке), 16 (карточки), 24 (шиты), 999 (пилюли).
- **Типографика** (Dynamic Type-совместимо, `allowFontScaling` включён):
  Display 34/41 semibold · Title 22/28 semibold · Headline 17/22 semibold ·
  Body 17/22 · Callout 16/21 · Footnote 13/18 · Caption 12/16.
- **Цвет**: нейтральная база, чтобы не спорить с фото.
  - `bg` #FFFFFF / dark #000000 (OLED, фото выглядят ярче)
  - `surface` #F5F5F7 / dark #1C1C1E
  - `textPrimary` #111111 / dark #F5F5F7, `textSecondary` 60% непрозрачности
  - `accent` — один фирменный цвет (по умолчанию тёплый коралловый #FF5A4E) — только для
    главного действия и наград
  - `keep` #34C759 (оставить), `trash` — НЕ красный, а `accent`/нейтральный: корзина — не
    опасность, это обратимое действие. Красный — только для настоящих ошибок.
  - `reward` — градиент accent → золотой #FFC83D, только в моменты награды.
- Контраст текста ≥ 4.5:1, крупного и иконок ≥ 3:1. Проверяй на фото: текст поверх фото —
  только на градиентной подложке или с блюром.

## Движение
Принцип: **движение объясняет, а не украшает**. Каждое движение отвечает на вопрос
«откуда это пришло и куда ушло».

| Тип | Параметры |
|---|---|
| Отклик на нажатие | scale 0.97, `withSpring({damping: 20, stiffness: 400})` |
| Появление элемента | 200–250 мс, `Easing.out(Easing.cubic)`, сдвиг 8–12pt + opacity |
| Переходы экранов | spring, `damping 22, stiffness 220`; shared element для фото grid → просмотр |
| Свайп-карточка | следует за пальцем 1:1, поворот до ±12°, порог — 30% ширины ИЛИ скорость > 800pt/с |
| Улёт карточки в корзину | по траектории жеста + уменьшение в иконку корзины (≤ 350 мс) |
| Счётчик ГБ | «прокрутка» цифр 400–600 мс |
| Награда | конфетти Skia ≤ 1,5 с, кольцо прогресса заполняется spring, затем тишина |

- Все анимации — на UI-потоке (`useSharedValue`, `useAnimatedStyle`), никаких `setState` в
  `onUpdate` жеста.
- Жесты прерываемы: пользователь может «поймать» летящую карточку.
- **Reduce Motion** (`useReducedMotion`): заменяй движение на fade 150 мс, без конфетти —
  статичная иллюстрация награды.

## Тактильная карта (expo-haptics)
| Событие | Отклик |
|---|---|
| Карточка пересекла порог свайпа | `selectionAsync` (один раз, при пересечении) |
| Фото перемещено в корзину / оставлено | `impactAsync(Light)` |
| Отмена действия | `impactAsync(Soft)` |
| Серия разобрана | `notificationAsync(Success)` |
| Достижение | `notificationAsync(Success)` + `impactAsync(Medium)` через 120 мс |
| Ошибка | `notificationAsync(Error)` |
Не больше одного отклика на жест. Уважай системную настройку вибрации.

## Производительность галереи (критично)
- Превью в сетке — через `expo-image` с размером превью (не оригинал!): ~ 200–300 px.
  На Android используй `MediaLibrary` thumbnails, на iOS — `ph://` с размером.
- `FlashList`: `estimatedItemSize`/фиксированный размер ячейки, `getItemType` для заголовков
  секций, `recyclingKey` в `expo-image` = id ассета. Ячейка — `memo`, без инлайн-функций.
- Не держи весь список ассетов в React-состоянии: страницы по 200–500, данные — в SQLite
  (`expo-sqlite`), в UI только видимое окно.
- Анализ фото — в фоне, с приоритетом ниже UI (см. `photo-analysis.md`). Скролл важнее анализа.
- Полноэкранный просмотр — предзагрузка соседних 1–2 фото (`Image.prefetch`).
- Меряй: Perf Monitor, React DevTools Profiler, Flashlight (Android). Регресс fps — блокер.

## Адаптивность
- Колонки сетки: `Math.max(3, Math.floor(width / 120))` — 3 на телефоне, 5–7 на планшете.
- Планшет/раскладушка в развороте: двухпанельный режим (серия слева, просмотр справа).
- Safe area везде (`react-native-safe-area-context`); нижние действия — над home-indicator.
- Dynamic Type до XXXL: кнопки растут в высоту, текст переносится, ничего не обрезается.
- Минимальная зона касания 44×44pt (48dp на Android).
- Тёмная тема — полноценная, не инверсия.
- Ориентация: портрет основная; просмотр фото поддерживает ландшафт.

## Ключевые паттерны Pickly

### Главный экран (хаб)
Сверху — кольцо «Место можно освободить: 3,4 ГБ» и одна главная кнопка «Начать разбор».
Ниже — карточки категорий с обложкой-коллажем и цифрой: Дубли · Похожие · Скриншоты ·
Картинки из WhatsApp · Люди · Места · Видео. Источники — чипы (Телефон, Яндекс Диск).

### Разбор серии — режим «Лучшее + свайпы»
Лучший кадр крупно с бейджем «Лучший» и коротким объяснением («Резче всех, у всех
открыты глаза»). Остальные — лента миниатюр снизу, по умолчанию отмечены «в корзину».
Главная кнопка: «Оставить лучшее · убрать 5 (48 МБ)». Тап по миниатюре — сделать её
лучшей/оставить. Одиночные фото — стопка свайп-карточек: влево — корзина, вправо — оставить,
вверх — «в избранное».

### Разбор серии — режим «Сетка»
Серия сеткой, лучшая отмечена короной. Тап — отметить в корзину (затемнение + иконка),
долгое нажатие — просмотр. Мультивыбор протягиванием пальца по сетке.
Переключатель режимов — в заголовке, выбор запоминается.

### Перемещение в корзину
- Нижний шит: «Переместить 12 фото в корзину Яндекс Диска? Их можно вернуть 30 дней».
  Для галереи iOS/Android после нашего шита система покажет свой диалог — предупреди об
  этом один раз в онбординге, чтобы он не пугал.
- После действия — тост с «Отменить» (5 с) и счётчиком освобождённого места.
- Пакетно: копи действия в «корзину сессии» и отправляй одним системным запросом в конце
  серии — меньше системных диалогов.

### Моменты награды
После серии — короткий экран: сколько освобождено, рост кольца, похвала (тексты — у
маркетолога), достижение если есть. Длится ≤ 2 с или до тапа. Не перекрывает работу:
при быстром разборе подряд — мини-версия в тосте.

### Состояния (обязательны)
Скелетоны с shimmer при загрузке · пустое состояние с иллюстрацией и следующим шагом ·
«Нет доступа к фото» с кнопкой в настройки · iOS «ограниченный доступ» с объяснением
выгоды полного · офлайн для Яндекс Диска · анализ идёт (прогресс + «можно уже разбирать
готовое») · всё чисто (праздник, не пустота).

## Чек-лист ревью дизайна
1. Фото — главный элемент экрана? Хром интерфейса минимален?
2. Одно главное действие на экране, оно очевидно и в зоне большого пальца?
3. Есть все состояния (см. выше)?
4. Каждое движение объясняет причину и следствие? Есть Reduce Motion?
5. Тактильный отклик соответствует карте, не избыточен?
6. Корзина не выглядит опасностью; «Отменить» доступно?
7. Списки: превью, а не оригиналы; нет ре-рендеров при скролле?
8. Dynamic Type XXXL, iPhone SE, планшет, тёмная тема — ничего не ломается?
9. Контраст, подписи для VoiceOver/TalkBack (`accessibilityLabel` у фото: дата, место, люди),
   порядок фокуса, зоны касания ≥ 44pt?
10. Токены вместо магических чисел?
