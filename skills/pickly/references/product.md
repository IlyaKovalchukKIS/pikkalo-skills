# Pickly — бриф продукта

Читай, когда нужен контекст продукта: новая фича, спорное решение, тексты, онбординг.

## Что это
Pickly — мобильное приложение, хаб фото и видео из галереи телефона и Яндекс Диска.
Помогает освободить место: находит дубли, похожие кадры, скриншоты, картинки из WhatsApp,
документы, тяжёлые видео; раскладывает по людям и местам и подсказывает лучший кадр
в серии. Разбор превращён в приятную привычку — **куратор лучших кадров**
(см. `gamification.md`): награда за выбор лучшего, а не за удаление.

## Главное обещание (инвариант)
**Pickly ничего не удаляет.** Фото только перемещаются в корзину хранилища пользователя:
- Android 11+ → системная корзина (`MediaStore.createTrashRequest`, 30 дней);
- Android 8–10 → своя корзина приложения на 30 дней (честно говорим об этом);
- Яндекс Диск → корзина Диска (`DELETE … permanently=false`);
- iOS (позже) → «Недавно удалённые».
Последняя копия файла защищена: нельзя убрать все копии одного снимка разом.
Любой код, текст или дизайн, который нарушает или размывает обещание, — блокер.

## Платформы и стек
- **Android первым**, iOS — следующим этапом (код пишем кроссплатформенным, проверяем Android).
- Expo (dev build) + React Native, TypeScript strict.
- Анализ — нативный модуль `modules/pickly-vision` (Kotlin; Swift — при выходе iOS).
  Алгоритмы переносятся из PhotoSeparator (`photo-analysis.md`, раздел «Перенос»).
- Бэкенд — **Yandex Cloud** (данные пользователей хранятся в РФ, 152-ФЗ):
  Cloud Functions + API Gateway + YDB Serverless + Lockbox для секретов.
- Распространение — APK с автообновлением. Магазины и оплата — позже (RuStore Pay /
  Google Play Billing за общим интерфейсом entitlement). Пока всё бесплатно; пейволл
  свёрстан, но скрыт флагом `paywallEnabled`.

## Источники (первый релиз)
1. Галерея телефона.
2. Яндекс Диск (REST API, OAuth Яндекс ID).
Позже: Google Drive, Dropbox, OneDrive.

## Первый релиз — объём
- Дубли (точные копии, включая «телефон ↔ Диск»), похожие кадры и серии, лучший кадр.
- Режимы разбора серии: «Лучшее + свайпы» и «Сетка» (выбор пользователя, запоминается).
- Категории: скриншоты, картинки из WhatsApp, документы и чеки, размытые/случайные.
- Видео: самые тяжёлые ролики и точные копии (без анализа содержимого).
- Люди (только по явному согласию) и места/поездки.
- Геймификация целиком (`gamification.md`), напоминания.
- Аккаунт и личный кабинет, отзывы со статусами.

## Приватность
Анализ — **только на устройстве**. На сервер не уходят ни фото, ни превью, ни эмбеддинги,
ни лица, ни геометки. Сервер знает только агрегаты: прогресс, награды, список
подключённых хранилищ (без токенов), отзывы.

## Аккаунт и кабинет
Вход: Яндекс ID (заодно даёт доступ к Диску) и Google; Apple — вместе с iOS.
Вход не нужен для первого разбора галереи — только для Диска, синхронизации, отзывов.
Разделы кабинета: прогресс и награды · хранилища · подписка · мои отзывы · настройки.

## Характер и бренд
Смешанный: спокойная премиальная работа с фото (фото — главный герой) и яркие моменты
награды. Фирменный цвет и маскот выбираются по прототипу (`prototype/`).

## Языки
Русский первым, английский заложен сразу (все строки через i18n).

## Репозитории и инфраструктура
- `Pickly` (приватный) — приложение, модуль `pickly-vision`, бэкенд Yandex Cloud.
- `pickly-skills` (публичный) — этот скилл, шаблоны, конвейер отзывов.
- Инфраструктура новая: свой Telegram-бот, своё приложение Яндекс OAuth, свой каталог
  Yandex Cloud. С PhotoSeparator ничего не делим.
- Чистый старт: данные пользователей PhotoSeparator не переносятся.
