# Роль: геймдизайнер Pickly — «куратор лучших кадров»

Идея: человек не «чистит мусор», а **собирает лучшие кадры своей жизни**. Удаление —
побочный эффект выбора. Награждаем за решения и привычку, никогда — за количество
удалённого. Тексты наград — по правилам `copy-marketing.md`, визуал и движение —
`ui-design.md` («Моменты награды»).

## Принципы
1. **Очки за решение, а не за удаление.** «Оставить всё» стоит столько же, сколько «убрать».
2. **Короткая радость, длинная привычка.** Мгновенный отклик ≤ 2 с, недельный ритм, месячные итоги.
3. **Из реальной галереи.** Квесты и итоги строятся по фото пользователя на устройстве.
4. **Без стыда и страха.** Пропуск прощается, потерь нет, сравнения с другими людьми нет.
5. **Приватность.** Витрина, квесты, люди, места, итоги — только на устройстве; на сервер — XP,
   уровень, значки, счётчики.

## Очки (XP)
| Действие | XP |
|---|---|
| Решение по серии (любое) | +10 |
| Выбран лучший кадр (наш или свой) | +5 |
| Решение по одиночному фото / скриншоту | +2 |
| Разобрана группа дублей | +3 |
| Категория разобрана полностью | +50 |
| Квест дня / недели | +100 / +300 |
| Полная Плёнка недели | +100 |
**Комбо**: 5 решений подряд, каждое быстрее 6 с, → ×1.5; 15 подряд → ×2. Сброс — пауза > 20 с.
**Антифарм**: после 400 XP за день — половина очков; «Отменить» отнимает начисленное.

## Уровни куратора
| Уровень | XP | Открывает |
|---|---|---|
| Новичок | 0 | — |
| Куратор | 500 | тема оформления «Плёнка» |
| Редактор | 2 000 | виджет на главный экран «Лучший кадр дня» |
| Архивариус | 6 000 | режим сравнения 2×2 |
| Хранитель историй | 15 000 | альтернативная иконка, золотая рамка Витрины |
Между уровнями — шкала с цифрами «до Редактора 340 XP». Новый уровень — отдельный момент
награды (полноэкранный, ≤ 2,5 с, с тем, что открылось).

## Плёнка недели (привычка)
- 7 кадров-ячеек (пн–вс). День «проявляется», если разобрана ≥ 1 серия или ≥ 10 решений.
- 1 автоматическая «заморозка» в неделю: один пропуск не ломает плёнку.
- Полная неделя → +100 XP и шаг к значкам «Четыре плёнки», «Сезон».
- Неполная неделя — просто начинается новая плёнка. Никаких «вы потеряли серию».

## Квесты (из галереи)
Генерируются на устройстве. Один **квест дня** (≤ 2 мин) и один **квест недели** (событие).
| Тип | Пример текста |
|---|---|
| Поездка | «Разберите поездку в Казань — 86 кадров, около 4 минут» |
| Скриншоты | «Скриншоты старше года: 140 штук, 320 МБ» |
| WhatsApp | «Картинки из WhatsApp за весну: 60 штук» |
| Видео | «Три самых тяжёлых видео — 2,4 ГБ» |
| Дубли | «Копии, которые уже есть на Яндекс Диске: 45 фото» |
| Серия дня | «Одна серия — один лучший кадр. 30 секунд» |
Квест всегда показывает реальное число, вес и время. Невыполненный квест молча заменяется.

## Витрина
- Каждый кадр, выбранный «лучшим», попадает в Витрину (можно убрать оттуда одним тапом).
- По воскресеньям — история «Ваша неделя в 12 лучших кадрах» (полноэкранные слайды с лёгким
  движением). «Поделиться» — только по кнопке, экспорт картинкой на устройстве.
- Витрина — эмоциональный центр: место, куда хочется вернуться, а не архив удалённого.

## Значки (25)
Редкость: обычный · редкий · эпический · секретный (силуэт «???» до получения).
| Группа | Значки |
|---|---|
| Первые шаги | Первая серия · Первый лучший кадр · Первый гигабайт |
| Привычка | Полная плёнка · Четыре плёнки (месяц) · Сезон (12 недель) |
| Объём | 1 ГБ · 5 ГБ · 10 ГБ · 25 ГБ освобождено |
| Мастерство | Свой взгляд (10 раз выбран не наш кадр) · Единодушие (50 раз согласились) · Комбо ×20 · Мастер выбора (100 серий) · Великий куратор (500 серий) |
| Категории | Чистый экран (все скриншоты) · Привет из WhatsApp · Без двойников (все дубли) · Лёгкое видео (топ-10 тяжёлых видео) |
| Истории | Порядок в поездке · Лица близких (назвали 5 людей) · Карта воспоминаний (10 мест) |
| Витрина | Первая витрина (неделя из 12 кадров) |
| Секретные | Ночная смена (разбор после полуночи) · Утренний кофе (разбор до 8:00) |
Закрытый значок показывает, как его получить (кроме секретных).

## Итоги месяца
1-го числа — история из 5 слайдов: освобождено и эквивалент («место для 300 новых фото»),
лучший кадр месяца, любимое место, кадры с близкими (если включены Люди), рост уровня.
Собирается на устройстве; поделиться — по кнопке.

## Ощутимые эквиваленты
1 ГБ ≈ 250 фото с телефона ≈ 4 минуты видео 4K. Показывать рядом с числом освобождённого.

## Мгновенные награды
| Когда | Что |
|---|---|
| Решение по фото | лёгкая вибрация, «+2» у счётчика |
| Серия разобрана | тост: «+15 XP · освобождено 48 МБ» и фраза похвалы |
| Конец сессии | экран итога ≤ 2 с: ГБ, XP, кольцо уровня, новые значки |
| Значок / уровень | полноэкранный момент с конфетти (Reduce Motion — без конфетти) |

## Напоминания, связанные с игрой
Не чаще 3 в неделю, только с поводом: «Плёнка недели: осталось проявить 2 кадра»,
«Готов квест: поездка в Сочи, 3 минуты». Без давления — правила `copy-marketing.md`.

## Чего не делать
Рейтинги между людьми · наказание за пропуск · очки за удаление · лутбоксы и платные
ускорители · уведомления ради возврата без пользы для пользователя.
